## 사용자와 합의한 작업 방향

원본 SMART-TIME PRO의 화면과 워치 기능을 최대한 유지하고 필요한 부분만 수정합니다. 기능별로 별도의 작은 앱을 계속 만드는 방식이 주 작업 방향이 아닙니다. `ble-minimal`은 설치·통신·센서 해석 검증용 소스로 보존합니다.

## 실제 확인한 결과

- Galaxy S25 Android 16에서 USB 업데이트 설치와 앱 시작 성공.
- 원본 건강·운동·제품 설정·사용자 설정 화면 진입.
- 원본 SDK에서 워치 등록·연결과 펌웨어 버전 표시.
- 원본 건강 화면에 실제 워치에서 동기화한 심박·걸음 데이터 표시.
- 기존 이름 필터 때문에 검색 목록에서 제외되던 등록 기기를 표시하도록 수정.
- 최종 휴대폰 다운로드 폴더의 APK와 배포 APK의 SHA256 일치.
- apksigner v2/v3 검증과 zipalign ZIP 정렬 검사 통과.

개인의 건강 측정값, 화면 캡처, MAC·USB serial과 전체 진단 로그는 이 공개 문서에 포함하지 않습니다.

## 보존한 것과 바꾼 것

원본의 XML·이미지·폰트·워치 SDK를 유지했습니다. 19개 DEX 중 17개는 이전 커스텀 기준 APK와 동일하며 `classes18.dex`와 `classes19.dex`를 수정했습니다. 검색 필터 및 선택 SDK의 초기화가 해당 변경에 포함됩니다.

광고 Manifest 진입점 67개 제거와 광고 초기화 차단, 음성·오디오 콘텐츠 초기화 비활성화, 불필요한 민감 권한 축소를 수행했습니다. 광고 SDK의 DEX 코드는 일부 남아 있으므로 완전 제거 완료로 보고하지 않습니다.

현재 INTERNET 권한이 없는 로컬 구성입니다. 원 공급자 서버의 로그인·날씨·온라인 다이얼·웹 기능은 연결되지 않습니다. 시작 안내는 현재 구성에 맞게 변경했습니다.

## 아직 확인하지 않은 부분

- 파일관리자로 APK를 다시 설치할 때 삼성·Google의 보안 판정이 어떻게 나오는지.
- 모든 원본 메뉴와 기능의 회귀 시험 및 다른 기기·OS의 호환성.
- 건강 수치의 정확도와 워치 전체 기록 대비 동기화 완전성.
- 고령자 사용성 평가, 게임 콘텐츠 연계와 임상 효과.
- 남아 있는 광고 SDK 전체 삭제 후 의존성 안정성.

기존 전체 분석 작업 공간의 원본 복원 경로와 현재 APK 기반 커스터마이징 경로를 혼동하지 않습니다. 다음 배포는 같은 서명키를 유지하고 versionCode를 10보다 높게 설정해야 합니다. 최근 추가한 빌드 스크립트는 별도 작은 APK로 메타데이터 변경→빌드→서명→검사 경로를 시험했으며, 이것이 새 기능 전체의 실기기 검증을 의미하지는 않습니다.
