# 비교 앱과 인증·설치 조건 비교

사용자가 제공한 비교 APK는 S25에 설치된 Mindrium base APK와 SHA-256이 동일했습니다. 설치 출처는 `com.sec.android.app.myfiles` → `com.google.android.packageinstaller`로 확인했습니다. 비교 APK 자체·소스·개인 기기 로그는 공개 저장소에 올리지 않았습니다.

| 항목 | 비교 앱 | 기존 Custom 0.1.0 |
| --- | --- | --- |
| 자체 서명 | 예, Android Debug 인증서 | 예, 이 작업에서 생성한 테스트 인증서 |
| RSA 키 | 2048비트 | 2048비트 |
| 인증서 알고리즘 | SHA256withRSA | SHA256withRSA |
| S25 실제 시각의 인증서 유효기간 검사 | 통과 | 통과 |
| APK 서명 검증 | v2 통과 | v2·v3 통과 |
| SourceStamp 검증 | 없음 | 없음 |
| targetSdk | 36 | 36 |
| 권한 선언(고유 이름 기준) | 11개 | 46개 |
| Activity / Service / Provider 선언 | 2 / 4 / 2 | 3377 / 25 / 16 |
| 문자 읽기·알림 접근 서비스 | 없음 | 있음 |
| 검사한 광고 SDK namespace | 발견 안 됨 | AdMob, Pangle, AppLovin, IronSource, Unity Ads, Meta, Vungle, MBridge, Bigo, Amazon 등의 정의 존재 |
| 사용자 기기 설치 | 확인됨 | 삼성 차단 화면에서 중단 |

광고 namespace 검사는 완전한 SDK 감사 또는 안전성 검사가 아닙니다. Flutter 앱의 Dart 코드 동작도 이 검사만으로 판정하지 않습니다. 서명 키의 발행 시점은 비교 앱이 2026년 3월, 기존 커스텀 키가 2026년 11월로 서로 다릅니다. 이 차이가 평판 판정에 영향을 미쳤는지는 알 수 없습니다.

이 결과는 ‘Mindrium은 공인 인증서를 받고 우리 앱은 서명하지 않아서 차단됐다’는 설명을 지지하지 않습니다. 두 APK 모두 자체 서명이며 유효합니다. 별도 개발자 등록·삼성 평판·예외 등록 여부는 APK만으로 확인할 수 없습니다. 서명 유효성과 보안 정책 승인은 구분합니다.

## 최소 앱을 통한 후속 검증

사용자는 최소 기능을 검색·연결·연결 해제로 선택했습니다. `ble-minimal/`에는 Android 표준 API만 사용하는 독립 코드로 이를 구현했습니다. 이전 광고 SDK·원본 실행 코드·네이티브는 포함하지 않습니다. 제조사 바인딩이나 건강 센싱 동기화는 구현하지 않았습니다.

기존 Custom 0.1.0과 같은 앱 ID·같은 서명 인증서·같은 min/target SDK를 유지합니다. 인증서 자체를 바꾸지 않은 상태에서 사용자가 같은 S25의 정상 파일 설치 UI로 검증해야 합니다. 설치 허용 시 인증서가 기기에서 일괄 차단된다는 설명은 약해지지만, 여러 구성 요소가 달라 특정 원인 하나를 입증하는 실험은 아닙니다. 현재 설치·실행·BLE 연결은 아직 미검증입니다.
